# 💬 Chat Realtime Application

## Giới thiệu dự án
Chat Realtime Application là một dự án backend được xây dựng nhằm mô phỏng hệ thống **chat thời gian thực 1–1** giống các ứng dụng nhắn tin phổ biến.

Dự án tập trung vào:
- Xây dựng **real-time communication** bằng WebSocket (STOMP)
- Thiết kế **RESTful APIs** kết hợp WebSocket
- Xử lý **xác thực người dùng bằng JWT**
- Lưu trữ và quản lý lịch sử tin nhắn

Mục tiêu của dự án:
- Áp dụng kiến thức **Spring Boot, WebSocket, Spring Security** vào dự án thực tế
- Hiểu rõ mô hình hoạt động của hệ thống chat realtime
- Chuẩn bị nền tảng cho vị trí **Java Backend Intern**

Hệ thống được thiết kế theo hướng rõ ràng, dễ mở rộng và phù hợp với kiến trúc backend trong doanh nghiệp.
